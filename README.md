# 掌中古蜀 · 三星堆

一个关于三星堆祭祀坑之谜的网页互动实验。

三千年前的一个夜晚，古蜀人把自己的神像砸碎、焚烧，按严格的顺序埋进坑里。
是谁做的？为什么？至今没有定论。

| 入口 | 内容 |
|---|---|

## 《结印》玩什么

对着摄像头做出古蜀祭司的手印，把沉在暗处的碎片唤回来。8 回合，时限递减，连击加分。

五个手印全部有出土文物为证：

| 手印 | 出处 |
|---|---|
| 环握 | 青铜大立人 · 金沙小铜立人（右手在上、左手在下） |
| 平举 | 二号神树座跪姿护卫 · 玉璋祭祀图跪拜人像 |
| 上托 | 铜顶尊跪坐人像 |
| 相向 | 扭头跪坐人像（两掌相向分开，掌间原嵌有物） |
| 独持 | 铜持龙立人像 · 铜持鸟立人像 |

## 考据

事实与假说严格分开：确凿的考古发现（碳十四测年、跨坑拼对、掩埋层序、灰烬成分）作为事实呈现；
"那一夜发生了什么"的四种解释一律标注为假说，不下定论。
资料来源与核对记录见 [research.md](./research.md)。

其中「跨坑拼对」是真实的：鸟足曲身顶尊神像由 1986 年二号坑、2021 年三号坑、2022 年八号坑出土的部件拼成，
分离三千年后合璧；因结构安全无法真正组合，馆内展出的是三维扫描与 3D 打印的"研究性复原"件。

## 技术

- **手势识别**：MediaPipe HandLandmarker（21 关键点 × 双手），几何规则判别五种手印
- **3D 复原**：Three.js，碎片用世界空间裁剪面切分，拖拽吸附归位
- 纯前端，所有画面处理都在本机完成，**不上传、不存储任何影像**

## 本地运行

python3 serve.py 8765          # http://localhost:8765
